# Input — входящая очередь

Сюда кладутся файлы на разбор. Это временная папка: после обработки файл
переносится в `docs/`, а `Input/` снова остаётся пустым.

## Правила

1. Файл в `Input/` считается необработанным.
2. Агент читает его, определяет тип и извлекает durable-знания:
   - термины → `GLOSSARY.md`;
   - решения → `docs/adr/`;
   - остальное остаётся источником.
3. Оригинал переносится без изменения содержимого:

   | Тип входа | Куда |
   |---|---|
   | Контекст проекта, vision, требования | `docs/context/` |
   | Исследования, выжимки, внешние источники | `docs/research/` |
   | Зафиксированные решения | `docs/adr/` (+ оригинал в `context/` или `research/`) |
   | Спецификации задач | `docs/specs/` |
   | Разное и временное | `docs/archive/YYYY-MM-DD/` |

4. Имя файла сохраняется. При совпадении добавляется суффикс, старый файл
   не перезаписывается.
5. Каждый разбор фиксируется в `docs/intake.md`.

## Git

Содержимое `Input/` не коммитится (см. `.gitignore`). В репозитории
остаётся только этот README.
